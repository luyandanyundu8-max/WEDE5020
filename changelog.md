## Changelog

### Version 1.0.0 – June 2026 (First Launch)

This is our first website release. Everything is new.

**What we added:**

**Pages:**
- Home page – welcome, brand story, featured cakes, seasonal flavours
- Products page – birthday cakes, wedding cakes, cupcakes, new cake flavours, and muffins with descriptions
- Order page – size selection, flavour choices, delivery form
- About Us page – our story and values
- Contact page – contact form, custom design requests, feedback form

**Features:**
- Navigation menu to move between pages
- Buttons on home page linking to order page
- Contact form that emails us directly
- Social media icons (Instagram and Facebook) in the footer

**Design:**
- Updated colour theme to warm, welcoming pastels
- Easy-to-read fonts
- High-quality cake photos from Unsplash
- Mobile-friendly layout (works on phones, tablets, computers)

**Tech setup:**
- Built with WordPress
- SSL security certificate for safe browsing
- Google Analytics to track visitors and popular cakes
- Domain name registered and hosting set up

**Other:**
- This README file
- Budget and timeline documentation
